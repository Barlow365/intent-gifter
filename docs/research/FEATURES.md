# Intent Gifter - Features Guide

**Comprehensive Feature Specifications**

---

## Core Features

### 1. Preference Capture

**Explicit Selection:**
- Browse catalog → add to wish list
- Save specific items you want

**Comparative Choice ("Pick 1 of 4"):**
- System shows 4 similar items
- User picks the one that "feels most like them"
- Earns +10 progress credits
- System learns preferences

### 2. Category Priority System

**8 Gift Categories:**
1. Cash / Flexible Credit
2. Experiences / Travel
3. Food & Drink
4. Clothing & Wearables
5. Home / Lifestyle
6. Tech / Gadgets
7. Toys / Games / Fun
8. Surprise Me

**User Actions:**
- Drag-drop to rank by preference
- Mark categories as "Never buy me this"
- Surprises only come from top-ranked categories

### 3. Progress System

**Progress Credits:**
- Earned via preference selections (+10 per choice)
- Never expire or reset
- Not cash, can't be withdrawn
- Visible progress bar

**Milestones:**
- 100 credits → 1st surprise
- 200 credits → 2nd surprise
- 500 credits → bonus reward

### 4. Surprise Mechanics

**Trigger:** Reach milestone → "See Your Surprise"

**Outcomes (Transparent Odds):**
- Progress Boost (+50 credits): 40%
- Discount (10% off): 30%
- Wish List Item: 15%
- Brand Item: 10%
- No Physical Item: 5%

**Rules:**
- No payment required
- Transparent odds shown upfront
- Progress retained regardless of outcome
- Milestone-based, not on-demand

### 5. Gift-Safe Profile

**Public Profile (shareable link):**
- Category rankings (safe → risky)
- Wish list items
- Progress state
- Boundaries ("Never buy me...")

**Friend View:**
```
Sarah's Gift Profile
Safest: Food & Drink, Experiences
Risky: Clothing, Tech
Never: Perfume, Jewelry
Wish List: Nike Jacket (70% progress)
```

### 6. Micro-Conversion (Optional)

**Accelerate Progress:**
- Pay $1 → gain +50 credits
- Limited to 3/month ($3 max)
- Framed as "speed up progress" not "buy chances"

## Advanced Features (Phase 2+)

### Brand Dashboard

For partner brands:
- Upload product catalog
- Target demographics
- Track engagement metrics
- View demand insights

### Friend Co-Funding

**Group Gifting:**
- Create gift fund
- Invite friends to contribute
- Vote on which item
- Auto-purchase when funded

### AI Recommendations

- Predict next items user will like
- Auto-generate "Pick 1 of 4" sets
- Optimize surprise outcomes
- Detect preference drift

## User Flows

### New User Onboarding
```
1. Sign up (email/password)
2. Rank 8 categories by priority
3. Mark boundaries ("Never buy me...")
4. First preference choice → +10 credits
5. "Keep going to unlock surprises!"
```

### Earning Progress
```
1. Log in → Dashboard shows progress
2. Click "Refine Preferences"
3. Pick 1 of 4 items shown
4. +10 credits earned
5. Progress bar updates
```

### Unlocking Surprise
```
1. Reach 100 credits milestone
2. "You unlocked a surprise! 🎁"
3. Click "See Your Surprise"
4. Animation reveals outcome
5. Claim reward (discount/item/boost)
```

### Friend Gifting
```
1. Friend receives profile link
2. Views gift-safe profile
3. Sees wish list + categories
4. Chooses item to buy
5. Checkout → gift sent
```
