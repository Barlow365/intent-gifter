**Total Effort:** ~350 hours (~9-11 weeks)

### Friend Co-Funding

**Use Case:** Multiple friends pool money to buy a big gift

**Workflow:**
```
1. Friend A starts gift fund for Sarah's birthday
2. Invites Friend B, C, D via link
3. Each contributes $25 = $100 total
4. System suggests items Sarah wants within budget
5. Friends vote on which item
6. Winner purchased & shipped to Sarah
7. Sarah receives gift + list of contributors
```

### Success Metrics

| Metric | Target |
|--------|--------|
| Group gifts created | 500+ per month |
| Average contributors per gift | 3-5 |
| Gift completion rate | 70%+ |
| Organic invites | 30%+ of new users invited by friends |

## Phase 4: Scale & AI

**Duration:** 12+ weeks
**Goal:** Advanced features, mobile app, AI recommendations

### Features

| Feature | Effort | Priority |
|---------|--------|----------|
| **Mobile App (React Native)** | 300h | High |
| **AI Recommendation Engine** | 200h | High |
| **Advanced Analytics** | 100h | Medium |
| **Subscription Model** | 80h | Medium |
| **International Expansion** | 120h | Low |

**Total Effort:** ~800 hours (~20 weeks)

### AI Recommendation Engine

**Features:**
- Predict next items user will like
- Auto-generate "Pick 1 of 4" sets
- Optimize surprise outcomes per user
- Detect preference drift over time

**Data Sources:**
- Comparative choices
- Wish list additions
- Category rankings
- Friend gifting patterns

### Mobile App

**Why:** 60%+ of users mobile-first

**Platform:** React Native (iOS + Android)

**Key Features:**
- Push notifications (milestones, gifts)
- Camera for wish list (photo → add item)
- Offline mode
- Apple/Google Pay integration

## Risk Mitigation

| Risk | Mitigation |
|------|------------|
| **Legal/gambling concerns** | Legal review, transparent design, no pay-to-win |
| **Low brand interest** | Prove demand first (MVP), then approach brands |
| **User churn** | Focus on retention features, progress never lost |
| **Competition** | First-mover advantage, data moat |
